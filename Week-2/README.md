# Week 2 – Data Acquisition and Preliminary Analysis

## Project Title
Campus Recruitment Data Acquisition and Preliminary Analysis

## Objective
This project focuses on acquiring, cleaning, and performing preliminary exploratory data analysis on a publicly available campus recruitment dataset using Python.

## Dataset
The dataset used for this project is the **Campus Recruitment Dataset**, which contains academic, demographic, employability, and placement-related information about students.

### Dataset Source
Kaggle – Campus Recruitment Dataset  
https://www.kaggle.com/datasets/benroshan/factors-affecting-campus-placement

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Kaggle Notebook

## Data Acquisition
The dataset was obtained from Kaggle and imported into Python using Pandas. The dataset was examined to understand its dimensions, columns, data types, missing values, and duplicate records.

## Data Cleaning
The preliminary cleaning process included:

- Checking for missing values
- Checking for duplicate records
- Reviewing data types
- Identifying inconsistent or inappropriate values
- Treating salary values carefully because salary is applicable only to placed students
- Preparing categorical and numerical variables for analysis

## Preliminary Analysis
The analysis focuses on:

1. Overall placement status
2. Placement rate
3. Relationship between work experience and placement
4. Relationship between MBA specialization and placement
5. Gender-wise placement patterns
6. Educational background and placement
7. Salary distribution among placed students
8. Correlation between numerical variables

## Key Findings
The dataset contains **215 student records** and **15 variables**.

- **148 students were placed**
- **67 students were not placed**
- Overall placement rate: **68.84%**
- Salary values were analysed only for placed students.
- Academic performance, work experience, specialization, and other employability-related variables were examined for their potential relationship with placement outcomes.

## Reproducibility
The analysis was performed using Python and standard data science libraries. The notebook included in this folder contains the analysis workflow and code used for data acquisition, cleaning, and preliminary exploration.
